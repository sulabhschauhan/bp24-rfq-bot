# BP24 WhatsApp RFQ Bot

AI WhatsApp bot answering automotive spare-part RFQs for BuyParts24, UAE.

**Status:** POC / pre-build

## Folder Structure

- `prompts/` — task inputs, one file per task (`<NN>_task.md`)
- `outputs/` — task results, one file per task (`<NN>_output.md`)
- `docs/` — design notes and reference documentation
- `src/` — application source code
